# Doma

Partner path: `/domains/doma/*`.

Secrets: DOMA_API_KEY, DOMA_PRIVATE_KEY. Optional DOMA_VERIFIED_UPLOAD, DOMA_NETWORK, DOMA_REGISTRANT_*.

Flow: check → quote → email verify (or verified upload) → POST register (x402) → poll order.

Docs: https://docs.doma.xyz/api-reference/domain-registration
