# MilyPay Security Audit - 2026-06-10 (Daily mode, 8/10 gate)

Scope: secrets, payment/proxy paths, CORS, float wallet. Stack: Next.js 16 on
Cloudflare Workers (OpenNext), Turso (libSQL), x402/AUDD via PayAI, Birdeye USDC proxy.

## Verified SAFE
- No secrets in git history or tracked files; all via `wrangler secret`. wrangler.jsonc
  `vars` are non-secret only (public wallet/mint, libsql URLs, emails, flags).
- .demo/.gnaf/.asic and build dirs gitignored and untracked.
- SQL injection: parameterized Turso queries + regex-sanitized FTS tokens.
- Email: contact route HTML-escapes user input; Resend JSON (no SMTP header injection).
- SSRF: markets proxy path is appended to a fixed Birdeye host; cannot escape authority.
- x402 /verify failure fails CLOSED (502, does not serve).
- No eval/exec/child_process; dangerouslySetInnerHTML only on static JSON-LD.

## Findings

### [MEDIUM] M1: Float drains if X402_ENABLED is unset
Confidence 8/10 - Phase 9 A02/A10 - src/lib/x402.ts withX402
The markets route is `alwaysPaid`, but the gate is `if (!enabled() || !paidHost)`. For
markets, `paidHost` is true, so the guard reduces to `!enabled()`. If `X402_ENABLED` is
ever not "true", markets serves FREE while still paying Birdeye in USDC -> float drain.
Float protection is coupled to one global flag.
Remediation: when `opts.alwaysPaid && !enabled()`, refuse (503) instead of free path.
Priority: P1.

### [MEDIUM] M2: Markets resale can run at a loss (economic abuse)
Confidence 7/10 - A06 Insecure design - src/app/api/markets + src/lib/x402pay.ts
Flat 0.05 AUDD (~$0.033) markup, but payAndFetch caps spend at 0.10 USDC (~$0.10).
Expensive Birdeye endpoints can cost more than the customer pays -> an attacker can pay
0.05 AUDD to make us spend up to 0.10 USDC, net loss per call. No global float budget.
Remediation: per-endpoint pricing, or lower maxAtomicUsdc below the AUDD-price equivalent,
or a daily spend cap. Priority: P1.

### [LOW] L1: HIGH-advisory transitive dependency (bigint-buffer)
Confidence 9/10 - Phase 3 - @solana/web3.js > bigint-buffer (+ postcss build, uuid)
bigint-buffer buffer-overflow advisory (HIGH). Pure-JS fallback in use, trusted input in
our path -> low real exploitability. postcss (build-time) + uuid (transitive) moderate.
Remediation: pnpm overrides to patched versions; track web3.js updates. Priority: P2.

### [INFO] I1: /api/status exposes the float hot-wallet address + balance
Public-by-design transparency, but advertises the hot wallet as a target. Consider not
exposing the exact wallet/balance. Priority: P3.

### [INFO] I2: Upstream error bodies returned to clients (markets 502 detail)
Minor info leak of Birdeye internal errors. Priority: P3.

### [INFO] I3: Hot-wallet keys are single-factor (Worker secret / local file)
SOLANA_PAYER_SECRET (float) and .demo/agent_wallet.json. Baseline OK; keep float small,
rotate periodically, no KMS. Priority: P3.
